INDUCLEAN WEBSITE V5

Deze map bevat de statische demo-website voor Induclean.

Inhoud:
- index.html
- styles.css
- script.js
- assets/ (logo en afbeeldingen)

GitHub Pages bijwerken:
1. Pak de ZIP uit.
2. Open de bestaande repository inducleanservices-demo op GitHub.
3. Upload de inhoud van deze map naar de hoofdmap van de repository.
4. Vervang index.html, styles.css en script.js en upload ook de map assets.
5. Klik op Commit changes.

Let op: het contactformulier opent de e-mailapp van de bezoeker. Voor directe online
verwerking is later een formulierdienst of backend nodig.
